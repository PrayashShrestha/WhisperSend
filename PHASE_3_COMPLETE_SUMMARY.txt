Successful Transcription Flow:

  1. User clicks button 🎤
     → Button turns yellow (connecting)
     → "🔄 Connecting..." appears briefly

  2. Connected and ready
     → Button turns red (recording)
     → Pulsing red glow shows active recording

  3. User speaks
     → Text appears in real-time (if enabled)
     → Recognizes speech patterns

  4. User stops speaking
     → Button returns to gray (idle)
     → Auto-submits on silence (0.5s default)

  5. Result shown
     → Green success toast appears
     → "✓ Transcribed: 'Your text here...'"
     → Auto-sends to ChatGPT (if enabled)
     → Toast auto-dismisses after 2.5s

ERROR RECOVERY FLOW:

  1. Click button
  2. Try to connect (yellow)
  3. Connection fails (red error state)
  4. Red error toast appears
  5. Can click button again to retry
