   Button now shows distinct states:
   
   State    Icon  Color        Animation

   Idle     🎤    Gray         None
   Connecting 🔄   Yellow       Pulse (1s)
   Recording 🔴    Red          Glow (1.5s)
   Error    ⚠️    Dark Red     Shake (0.5s)

   • Connecting Pulse: Yellow fade (1s infinite)
   • Error Shake: Attention getter (0.5s)
   • Button Hover: Scale +8% (0.2s)
   • Button Click: Scale -4% (0.2s)

   • Clear error messages on failure

   Improved error system:
   
   • Error type differentiation (5 types)
   • Type-specific messages
   • Visual button state update
   • Clear recovery path
   • Better user guidance
